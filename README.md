# OTRG (working name TRUST-GRAF): out-of-time reliability gating on the Elliptic transaction graph

Code label `TRUST-GRAF` = manuscript name OTRG (out-of-time reliability gating). The rename is explained in `reports/final_research_integrity_report.md`.

## Reproduce (CPU only; about 30 min for the main run on 2 cores, about 10 min per GCN seed)
```
pip install -r requirements.txt
# put elliptic_txs_{features,edgelist,classes}.csv in RAW/ (Kaggle "Elliptic Data Set" or https://data.pyg.org/datasets/elliptic/)
python3 -I src/data_audit.py RAW data            # forensic audit + parquet cache; check SHA-256 in data/dataset_manifest.json
python3 tests/test_units.py                      # gradient check + gate routing test (synthetic data, tests only)
python3 run_experiments.py --skip-gcn            # tuning, cross-fitting, experts, baselines, fusion variants
python3 experiments/refit_fusion.py              # documented penalty selection on steps 30-34 (validation only)
python3 experiments/run_gcn.py 42 1 7 123 2024   # GCN baseline
python3 experiments/statistical_tests.py         # metrics, calibration, paired bootstrap, Wilcoxon, Holm, gate diagnostics
python3 experiments/robustness.py                # feature-noise and edge-removal stress tests, saves models
# revision-2 experiments (each heavy command under: flock /tmp/cpu.lock ...)
python3 experiments/degree_preserving_control.py          # degree-preserving rewiring control (see script header for modes)
python3 experiments/run_gnn_v2.py gcn_seeds 123 2024; python3 experiments/run_gnn_v2.py sage 42 1 7 123 2024; python3 experiments/run_gnn_v2.py mowst 42 1 7
python3 experiments/robustness_v2.py; python3 experiments/tuning_sensitivity.py
python3 -I experiments/second_dataset/audit_convert.py ...; see reports/fix_second_dataset.md for the exact second-dataset commands
python3 experiments/statistical_tests.py; python3 experiments/statistical_tests_v2.py; python3 experiments/gate_diagnostics_v2.py
python3 experiments/make_figures.py; python3 experiments/ledger.py; python3 experiments/ledger_v2.py; python3 experiments/integrity_check.py
cd manuscript && pdflatex main && bibtex main && pdflatex main && pdflatex main
```
All manuscript numbers come from `manuscript/numbers.tex` and `manuscript/tables/*.tex`, both generated by `experiments/ledger.py` from `results/`.

## Layout
`src/` preprocessing (splits, neighbourhood view, edge shuffle), model (experts/baselines), fusion (gate), evaluation (metrics, Platt).
`baselines/gcn.py` GCN. `experiments/` evaluation, statistics, robustness, figures, ledger. `results/` CSVs, predictions, models. `reports/` audit documents.

## Data, licences and saved predictions
The Elliptic data set (Weber et al., 2019) is distributed by Elliptic on Kaggle (https://www.kaggle.com/datasets/ellipticco/elliptic-data-set) under the Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International licence (CC BY-NC-ND 4.0). The YelpChi and Amazon graphs come from the CARE-GNN repository (https://github.com/YingtongDou/CARE-GNN). No raw data and no class labels are redistributed here: `scripts/download_data.py` and `src/data_audit.py` obtain the original files and check their SHA-256 digests.

The saved test-period predictions of every model and seed (the `results/preds*` and `results/second_dataset/preds*` folders, about 47 MB of `.npz` files) are archived as a Kaggle data set, https://www.kaggle.com/datasets/muniraja1292/otrg-elliptic-predictions, as 15 parts (`otrg_predictions_part01.zip` to `otrg_predictions_part15.zip`), and are also included in the article's Supplemental Data S2. Unpack every part into the repository root; each part stores its files under their `results/...` paths. The label vector `y` was removed from `_meta.npz` and from the second-data-set split files; after building the local data caches, run

```
python3 -I scripts/restore_labels.py
```

to write the labels back from your own downloaded copies before running any analysis script. The restored files are identical to those used for the article.
